# Core Web Vitals Checklists

Index of Apogee open-source **templates and checklists** for Core Web Vitals monitoring. Start here, then open the repo that matches how you want to work.

**Apogee on GitHub:** [apogee-information-systems.github.io](https://apogee-information-systems.github.io/) — open-source packages, blog, and public tools from [Apogee Information Systems](https://apogee.gr).

## Repositories

| Repository | Role | Best when |
|------------|------|-----------|
| [cwv-monitoring-checklist](https://github.com/Apogee-Information-Systems/cwv-monitoring-checklist) | Fork-friendly checklist + issue forms | You want a light SOP to copy into docs or run as GitHub Issues |
| [agency-cwv-playbook-template](https://github.com/Apogee-Information-Systems/agency-cwv-playbook-template) | Full playbook template (runbooks, clients, ops inventory) | You want one ops repo per agency with “Use this template” |

Both are tool-agnostic (PageSpeed Insights, Lighthouse CI, Apogee Watcher, or any CWV stack). Canonical deep-dive for the monitoring SOP:

**Canonical article:** [Core Web Vitals Monitoring Checklist for Agencies](https://apogeewatcher.com/blog/core-web-vitals-monitoring-checklist-for-agencies)
